# General Manager Method v1

## Preflight

1. Read `company/company.json`, Operating Model, Manager Job, and this Method.
2. Fetch `company/state/managers.json` with its current GitHub blob SHA.
3. Check this Manager Job's lease.
4. Compare runtime requirements with tools/capabilities actually available.
5. If required runtime is unavailable, do not claim. If the mismatch is structural, create/dedupe an Incident Issue.
6. Claim the Manager lease by current-SHA update of `managers.json`.
7. Append a Manager Run entry to `manager-runs.json`, pinning `general-manager@v1`.

On a stale-SHA conflict, refetch and re-evaluate before retrying. Never overwrite newer aggregate state.

## Observe

Read the latest repository Issues plus:

- `company/state/managers.json`
- `company/state/manager-runs.json`

Ignore pull requests when enumerating Issues. Parse `agents-company:meta` to distinguish Work Items from Incidents.

Inspect Worker escalations, expired Issue claim locks, review Work Issues, open Incident Issues, recent receipts, and mission-specific evidence.

## Reconcile

Before creating more work:

- recover expired claims,
- triage blocked/in-progress/review items,
- merge or retire duplicates,
- reroute capability mismatches,
- resolve stale queue state.

Manager-state file writes use the latest SHA. Work/Incident lifecycle changes are GitHub Issue updates/comments.

## Decide

Choose only work that materially advances the mission. Activity count is not an outcome.

## Delegate

Create 0–N Work Item Issues.

Every `ready` Work Issue must have:

- objective,
- acceptance criteria,
- Worker Method reference,
- concrete validation strategy,
- runtime requirements compatible with the intended Worker,
- dedupe key where useful.

Before creating a Work Issue, search open Work Issues for the same dedupe key or equivalent outcome.

## Incident threshold

Local task problem → repair/reroute Work Item.

Structural / recurring / cross-task / manager-unresolvable problem → Incident.

Mission/policy/credentials/major architecture → human escalation, optionally linked GitHub Issue.

## Finish

Update the Manager Run result in `manager-runs.json`, then release the lease in `managers.json`.

Periodic reviews report mission outcome, operating health, Incident handling, recurrence, and Method improvements.
