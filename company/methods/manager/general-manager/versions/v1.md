# General Manager Method v1

## Preflight

1. Read `company/company.json`, Operating Model, Manager Job, this Method version.
2. Read the Manager lease file with its current GitHub SHA.
3. Compare runtime requirements with tools actually available.
4. If required runtime is unavailable, do not claim. If the mismatch is structural, create/dedupe an Incident.
5. Claim the Manager lease by current-SHA update and create a Manager Run file.

## Observe

Inspect:
- open Work Items,
- Worker escalations,
- active/expired claims,
- open Incidents,
- recent completed receipts,
- mission-specific source evidence.

## Reconcile

Before creating new work:
- recover expired claims,
- triage blocked/in-progress/review items,
- merge/retire duplicates,
- reroute capability mismatches,
- resolve stale queue state.

## Decide

Choose only work that materially advances the mission. Activity count is not an outcome.

## Delegate

Create 0–N Work Item files. Every `ready` item must have:
- objective,
- acceptance criteria,
- Worker Method reference,
- concrete validation strategy,
- runtime requirements compatible with the intended Worker,
- dedupe key where appropriate.

## Incident threshold

Local task problem → repair/reroute Work Item.

Structural / recurring / cross-task / manager-unresolvable problem → Incident.

Mission/policy/credentials/major architecture → human escalation, optionally linked GitHub Issue.

## Finish

Write the Manager Run result and release the Manager lease. Weekly/periodic runs report mission outcome, operating health, Incident handling, recurrence, and Method improvements.
